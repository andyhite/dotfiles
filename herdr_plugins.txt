# Herdr plugins, one per line: <owner>/<repo>[/<subdir>][@<ref>]
# install.sh feeds each line to `herdr plugin install`, which is also how herdr
# updates an already-installed plugin. Pin a tag/branch/commit with @<ref>;
# without one you get the repo's default branch at install time.
# Two things live outside this file:
#   - Per-plugin settings, in config/herdr/plugins/config/<plugin_id>/, which is
#     symlinked to ~/.config/herdr/plugins/config. Not every plugin uses it —
#     ghzinga reads its config from elsewhere entirely (see its note).
#   - Keybindings, in config/herdr/config.toml. herdr has no [keys] entry for
#     plugin actions, so each one is a [[keys.command]] block shelling out to
#     `herdr plugin action invoke`.
#
# A spec line ending in `# local-only` is skipped when install.sh runs inside an
# ssh session ($SSH_CONNECTION set), for plugins that only make sense on the
# machine you physically sit at.

# Chromium in a pane, drivable over CDP. Ships the herdr-browser omp skill that
# the `skills` step symlinks into ~/.omp/agent/skills.
ogulcancelik/herdr-browser

# Local diff/review TUI in a split pane — a Rust app reading git, not an AI
# reviewer. Also opens on the worktree.created event. Config: config.toml.
persiyanov/herdr-reviewr

# Mirrors a *remote* herdr server into this one's sidebar over ssh or
# `docker exec` — remote panes appear as local workspaces. No listener, no port.
#
# local-only because it inverts over ssh: installed on a box you've ssh'd into,
# it would mirror some other machine's herdr back into the session you're
# already viewing remotely. The laptop is the only place this makes sense.
nikok6/herdr-mirror  # local-only

# Directional pane focus that hands off to nvim splits instead of stopping at
# the pane edge (vim-tmux-navigator, for herdr). Two-sided: the herdr half is
# the ctrl+h/j/k/l bindings in config/herdr/config.toml, the nvim half is
# config/nvim/lua/herdr-nav.lua.
paulbkim-dev/vim-herdr-navigation

# Ctrl-click a github.com issue/PR link in any pane and it opens in a ghzinga
# TUI split. The plugin is pure wiring; all behaviour and all config belong to
# the `gzg` binary — `cargo install ghzinga`, configured in config/ghzinga/.
osolmaz/ghzinga/plugins/herdr

# Inbox for agent panes, plus session/tab naming — it can auto-rename tabs, so
# it replaces iurysza/herdr-tab-smart-rename (and the andyhite fork of it that
# patched max_tokens -> max_completion_tokens for OpenAI reasoning models).
douglascorrea/herdr-agent-inbox

# Live token spend dashboard + cost notifications. Reads Pi/OpenCode/Claude
# session files — it lists omp panes but can't price them, and there is no
# Codex support. Exposes no configuration at all.
Davidcreador/herdr-token-dashboard

# JanTvrdik/herdr-command-palette was here until the palette became
# config/herdr/palette/palette.sh, run straight from a `type = "popup"`
# keybinding. It has to be a keybinding rather than a plugin because fzf needs
# a TTY and a plugin action doesn't get one — as a plugin it had to host the
# picker in an `overlay` pane, which covers the whole canvas. Still the reason
# most plugin actions here are deliberately left unbound: all 41 of them are
# one fuzzy search away rather than needing a key each.

# Runs setup steps in a new worktree on worktree.created: copies .env* from the
# main checkout, `mise trust`, `direnv allow`, installs deps. A worktree per
# issue otherwise starts with none of its gitignored files. No actions, pure
# event hook. Config: config.toml.
tdi/herdr-worktree-setup

# Declarative tab/pane layouts applied to each new worktree, chosen by repo and
# branch glob, with real `herdr agent start` panes rather than typed commands.
# Owns the layout of new worktrees — which is why reviewr's auto_open is off.
# Also ships `remove-gone` to clear worktrees whose upstream branch was deleted.
# Config: config.yml. Compiles itself with cargo on first use.
razajamil/herdr-plugin-workspace-manager

# The focused agent's branch PR state as a sidebar token — "#123 ✓". Needs $pr
# in [ui.sidebar.agents] rows to render at all. Ambient status only; ghzinga is
# still the thing that opens a PR to read it.
wyattjoh/herdr-plugin-gh-pr
